## Source

**[Lilygo T-Beam SUPREME TS1 Case by Alley Cat](https://www.printables.com/model/705817-lilygo-t-beam-supreme-ts1-case-by-alley-cat)**

What the reference is for: **curved features, strap slots, textured surface
lines.** Shots that show those three clearly are the useful ones.

## Before committing anyone else's photos

> [!IMPORTANT]
> **The model's license has not been checked.** Printables listings carry a
> per-model license — some permit reuse with attribution, some do not permit
> redistribution at all. Open the listing, read the license field, and only
> commit the author's photos if it allows it. Credit **Alley Cat** and link
> the listing either way.
>
> If the license does not allow it, the link alone is enough — the written
> description in
> [Aesthetics and design](../README.md#aesthetics-and-design) carries the
> intent without the pictures.

Photos of **our own** prints have no such problem. Once the first shells come
off the printer, those are the better reference anyway.
